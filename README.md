# Script Wallpapers e Lockscreen do Intune
Script de Powershell que permite aplicar imagens de wallpaper e lockscreen pelo Intune.


## **Conteúdo:**

Config Windows LAPS.ps1

Config Windows LAPS.exe

Criação dos grupos do Windows LAPS.ps1

## **Instruções:**

**Neste exemplo, os objetos Computadores que vão utilizar o Windows LAPS estão na OU (Unidade Organizacional) chamada LAPS. O grupo que terá o direito de ler a senha do Windows LAPS será gabriellaps.lan\Group LAPS (nome do domínio: gabrielluiz, nome do grupo: Group LAPS). Esse mesmo grupo também terá o direito de redefinir a senha do Windows LAPS. A auditoria de sucesso será aplicada a Todos (Everyone).**
